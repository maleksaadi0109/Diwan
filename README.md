# ديوان — Diwan (Arabic Poetry Desktop App)

تطبيق مكتبي متقدم للشعر العربي مبني باستخدام **Tauri 2** و **React** و **TypeScript** و **Tailwind CSS**، مصمم للمحاذاة الصوتية الدقيقة وعرض القصائد وتفسيرها بالكامل دون الحاجة للاتصال بالإنترنت.

---

## الميزات الأساسية (Phase 1)

- **واجهة عربية أصيلة (RTL)**: متوافقة مع قواعد الخطوط الشعرية (`Amiri` للأبيات و `Cairo` للأزرار والتحكم).
- **نظام لوني داكن ودافئ**: خلفيات فحمية دافئة، سطوح ورقية مستوحاة من المخطوطات، ولمسات ذهبية كهرمانية.
- **مكتبة القصائد**: استعراض، وتصنيف حسب العصور الأدبية (جاهلي، إسلامي، عباسي، أندلسي، إلخ)، والبحث السريع في العناوين والشعراء والأشطر مع معالجة التشكيل والهمزات.
- **مشغّل القصيدة المتزامن**: استعراض الأبيات وتقسيمها إلى (صدر وعجز)، تتبع البيت النشط أثناء الاستماع، القفز السريع بالضغط، وتعديل سرعة التشغيل ومستوى الصوت.
- **شاشة الاستيراد**: إضافة قصائد جديدة يدوياً وتحديد الفواصل بين الشطرين وإرفاق التسجيلات الصوتية.
- **إعدادات متكاملة**: تخصيص أحجام الخطوط، اختيار نماذج الذكاء الاصطناعي (Faster-Whisper / Silero VAD)، والاطلاع على الخصوصية.

---

## متطلبات التشغيل والتطوير (Prerequisites)

1. **Node.js**: الإصدار 18 فما فوق (تم التحقق على `v24.18.0`).
2. **Rust & Cargo**: الإصدار الحديث من Rust (تم التحقق على `1.97.1`).
3. **مكتبات النظام لنظام Linux**:
   - `webkit2gtk-4.1` أو `webkit2gtk-4.0`
   - `gtk+-3.0`
   - `libsoup-3.0`
   - `openssl`
   - `pkg-config`
4. **Python**: الإصدار 3.10 فما فوق مع `ffmpeg` للمعالجة الصوتية.

## أوامر التشغيل (Getting Started)

### تثبيت الحزم
```bash
npm install
```

### تشغيل واجهة الويب في وضع التطوير
```bash
npm run dev
```

### تشغيل تطبيق الديسكتوب (Tauri Dev)
```bash
npm run tauri dev
```

### فحص الأنواع (Type Checking) والترجمة (Build)
```bash
npm run build
```

### تشغيل الاختبارات
```bash
npm test
```

### فحص التنسيق والجودة (Lint)
```bash
npm run lint
```

## هيكل المشروع (Project Structure)

```text
arabic_poem/
├── src/
│   ├── components/         # المكونات المشتركة (Navigation, Header, Badge)
│   ├── data/               # البيانات التجريبية (MOCK_POEMS, MOCK_POETS)
│   ├── features/
│   │   ├── library/        # شاشة ومكونات المكتبة والبحث
│   │   ├── player/         # مشغّل القصيدة وعرض الأبيات
│   │   ├── import/         # استيراد القصائد والتسجيلات
│   │   └── settings/       # الإعدادات وتخصيص الخطوط
│   ├── hooks/              # الخطافات المخصصة (usePoemPlayback)
│   ├── lib/                # دوال مساعدة ومعالجة النصوص العربية والوقت
│   ├── styles/             # ملفات التنسيق العامة والخطوط
│   └── types/              # تعريفات الأنواع (Poem, Verse, Alignment, Poet)
├── src-tauri/              # كود نظام Tauri 2 المكتوب بلغة Rust
│   ├── capabilities/       # تصاريح Tauri
│   ├── src/                # أوامر Rust الخلفية
│   └── tauri.conf.json     # إعدادات التطبيق والنافذة
├── worker/                 # مساحة معالج الصوت والذكاء الاصطناعي في بايثون
└── README.md
```
